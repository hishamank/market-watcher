# Alpaca fixtures

**Hand-written, not recorded.** No Alpaca keys were used to build the adapter, so every file here is written by hand from the example payloads and field lists in Alpaca's official docs. The docs show only fragments of most payloads, so the full shapes are put together from the documented field lists, and the values are made up. Replace them with real recordings after the first keyed run.

The scenario is Tuesday 24 June 2025, a regular session from 09:30 to 16:00 New York time (13:30 to 20:00 UTC).
