# Supplemental stock data alternatives

Checked 2026-11-26. Research only; recommendation, not an adopted architecture decision. Scope: Finnhub, Financial Modeling Prep (FMP), Alpha Vantage. Alpaca/Yahoo/RSS are researched separately.

**Recommendation:** no provider here is a verified free option for a public hosted project. Keep the simulator demo self-contained. For a private prototype, Finnhub is the strongest starting point for metrics, news and earnings, but its free profile lacks company description and sector. If all target fields must come from one provider, investigate FMP with explicit display permission and suitable endpoint coverage. Do not buy a personal subscription assuming it grants public display rights.

## Evidence and limits

Official documentation, pricing and terms were inspected. Finnhub's documentation embeds its endpoint schema in HTML; its pricing is rendered by the site's JavaScript bundle, which was also inspected. No account keys or `.env` files were read. **Authenticated tests: NOT RUN** for all three providers. Coverage, freshness, nulls, units and actual account entitlements remain unverified. An Alpha Vantage public `apikey=demo` overview request returned an informational key message, not company data; this does not establish free-account access. [Demo URL](https://www.alphavantage.co/query?function=OVERVIEW&symbol=IBM&apikey=demo)

## Implications for this project

These are research recommendations, not implementation changes:

- Public demo: use clearly labelled synthetic supplemental fixtures or omit unavailable optional sections until display rights are confirmed. A copied provider snapshot is still provider data.
- Private provider evaluation: Finnhub first for news/calendar/metrics; FMP first if description and sector are essential. Neither is authenticated-tested here.
- With permission: fetch and cache by symbol in the gateway, independently of streaming quotes. Preserve source/as-of information and unavailable states. Treat earnings dates as estimates, and distinguish zero dividend yield from missing data.
- Budget by upstream refreshes, not page views. At one overview request per symbol, 50 symbols already exceed Alpha Vantage's standard 25/day allowance; shared caching cannot remove that initial coverage cost. Paid overview access is a separate constraint.
- ETF coverage needs separate validation: the app includes ETFs, while company profiles, P/E and company earnings may not apply. Do not fabricate company statistics for funds.

No implementation, dependency changes, commits, pushes or PRs were made. Application checks and feature verification were not run for this research-only note.
