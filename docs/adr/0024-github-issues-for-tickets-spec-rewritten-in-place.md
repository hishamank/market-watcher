# GitHub issues for tickets, and the spec rewritten in place

The repository lives on GitHub. Tickets are GitHub issues with labels for tier, lane and agent status, and `docs/roadmap.md` orders them and shows dependencies; agents report blockers where the work is tracked. The final spec replaces `docs/spec.md` in place, using the to-spec template (problem, solution, user stories, implementation decisions, testing decisions, out of scope) plus the build order and links to the ADRs. It is not published to the issue tracker.
