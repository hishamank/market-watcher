# Server-side watchlist keyed by an anonymous device ID

When the server-side watchlist lands (the last extra), each device creates a random ID on first launch and keeps it through the storage interface. The gateway serves `GET /watchlist` and `PUT` and `DELETE /watchlist/:symbol` with an `X-Device-Id` header, and stores watchlists in Node's built-in SQLite, so no dependency is added (on a volume when hosted). Toggling stays optimistic through the same hook (ADR 0014) and rolls back with a toast on failure. On first sync, stars that exist only on the device are uploaded once, and from then on the server is the source of truth, with device storage kept as the offline copy. Quick authentication could later replace the device ID (optional). The hook and the endpoints keep their shape, and only the identity changes.
