# Pinned toolchain and a one-command start

Node 26 LTS is pinned in `.nvmrc` and `engines`, and pnpm through the `packageManager` field, so every machine and agent worktree builds with the same tools. Node 26 no longer ships Corepack, so a fresh checkout installs any pnpm 10 (`npm install -g pnpm@10`), which then switches itself to the pinned version from `packageManager`. CI installs it with `pnpm/action-setup`, which reads the same field. `pnpm i && pnpm dev` starts the gateway in simulator mode and the web app through Turborepo, and the Expo app joins once it exists. `.env.example` documents every variable, and the simulator needs none.
